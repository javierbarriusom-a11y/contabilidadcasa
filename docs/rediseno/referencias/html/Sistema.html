Sobrio, numérico, honesto con lo que no sabe

Una cifra protagonista por pantalla, cada cifra con su estado (real, estimada o sin dato) y nada que ocupe sitio si no tiene datos. Se sustituyen las variables CSS actuales; la estructura de motores no cambia.
